# Product Documentation - Viewing Management

Coordinate physical property inspections safely on the HomeHunt platform.

## Workflow

1. **Viewing Request**:
   - Seeker selects a preferred date/time and drafts instruction notes.
   - The request automatically appears as an interactive system card inside the conversation thread.

2. **Availability Matching**:
   - Landlords define their weekly availability slots. Requests falling outside slots are rejected.

3. **Double-Booking & Conflict Checks**:
   - The platform prevents overlapping bookings for a listing. If a slot is confirmed, concurrent pending requests are automatically invalidated.

4. **Outcome Feedback Loop**:
   - Once the appointment date passes, seekers leave structured feedback ("INTERESTED", "NOT_INTERESTED", "NOT_AS_DESCRIBED", etc.).
   - Dislikes refine user preferences in the Phase 5 matching system.
   - Misleading listings trigger automated verification reports in the Phase 4 queue.
