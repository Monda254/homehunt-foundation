# Product Documentation - Housing Journey Timeline

HomeHunt maps seeker interactions across stages to establish journey records.

## Journey Pipeline

1. **SAVED (Saved Home)**:
   Seeker bookmarks listing (Phase 3 Favorites).

2. **CONTACTED (Contact Initiated)**:
   Seeker sends an enquiry (creates a conversation thread).

3. **VIEWING_REQUESTED**:
   Seeker schedules inspection slot.

4. **VIEWING_CONFIRMED**:
   Landlord accepts date/time slot.

5. **COMPLETED (Property Viewed)**:
   Viewing appointment date passes and inspection takes place.

6. **OUTCOME (Feedback recorded)**:
   Seeker submits feedback. Refines personalization logic (Phase 5) and flags discrepancies (Phase 4).
