# Product Documentation - In-App Communication

The HomeHunt communication system is housing-specific. It links seekers directly with landlords, agents, and property managers in the context of active marketplace listings.

## Key Features

1. **Structured First-Contact**:
   Seekers discover a listing and initiate an enquiry using template messages or free-form text. The platform creates a unified communication thread.

2. **Context-Rich Header**:
   Both parties see the property context header (listing title, rent price, image, location, and verified badges) directly above the chat feed, ensuring context is never lost.

3. **Template Quick-Replies**:
   Quick-tap answers to common questions ("Is this property still available?", "Are pets allowed?") speed up tenant-landlord alignment.

4. **Security & Moderation Controls**:
   - **Blocking**: Block a user to immediately end all communication and lock active threads.
   - **Abuse Reporting**: Report harassment, scams, or misleading listing specifications directly to Phase 4 moderation queue.
   - **Rate Limiting**: Throttles rapid thread creation (max 5/hour) and message spams (max 60/min).
